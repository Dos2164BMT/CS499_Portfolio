Professional Self-Assessment

From infrastructure experience to complete computing solutions

Completing the Computer Science program at Southern New Hampshire University changed how I approach technical problems. My professional background includes fiber-optic networks, routers, switches, gateways, network video recorders, surveillance systems, and customer internet services. Coursework in software development, testing, algorithms, databases, full-stack development, and secure coding taught me to connect that infrastructure experience with disciplined software engineering. I no longer view networking and programming as separate paths. I see software, automation, and data as essential parts of reliable modern operations.

The program strengthened my ability to collaborate in a team environment by teaching me to make technical work understandable and reproducible for others. Version-controlled source, focused commits, descriptive identifiers, automated tests, documented setup steps, and structured reports allow another developer to review a decision and continue the work. Course experiences involving requirements, Agile roles, testing, and code review also taught me to separate feedback about a solution from feedback about a person. I use requirements and observable evidence to build shared understanding, reduce ambiguity, and support organizational decisions.

Communication with stakeholders is equally important. A manager needs risk, progress, and business impact; a developer needs interfaces, constraints, and test evidence; an end user needs clear behavior and useful error messages. Across this portfolio I communicate through a recorded code review, written narratives, diagrams, README instructions, JSON reports, and this accessible web presentation. This range demonstrates my ability to adapt technical information without losing accuracy.

My work with data structures and algorithms taught me to evaluate design choices instead of selecting a structure only because it is familiar. The network-automation planner indexes devices in dictionaries for average constant-time lookup, uses sets for duplicate detection, sorts numeric IPv4 intervals to detect overlap in O(n log n), and models dependencies as a directed graph. Kahn's topological-sort algorithm orders tasks in O(V + E), while a min-heap makes valid execution order deterministic. These decisions demonstrate that correctness, scalability, and explainability can reinforce one another.

Software engineering and database coursework prepared me to design cohesive systems instead of isolated scripts. In the Appointment Service, centralized validation, custom exceptions, defensive copies, dependency injection, immutable snapshots, and focused tests improve maintainability and reliability. In the database artifact, a normalized SQLite schema separates devices, task requests, dependencies, execution runs, results, and audit events. Primary and foreign keys, constraints, indexes, transactions, and parameterized queries protect integrity while preserving a useful operational history.

Security is a design requirement throughout my work. I validate inputs before they reach state-changing operations, reject unknown SSH host keys, keep credentials in environment variables, default network automation to dry-run mode, require an explicit apply flag, use bound SQL parameters, and exclude credentials from persistent storage. I also use rollback commands, atomic database transactions, bounded history queries, and failure-oriented tests. These controls reflect a mindset of anticipating misuse, minimizing exposure, and failing safely.

My goal is to contribute as a network automation, systems, DevOps, or software engineer in an organization where reliable infrastructure and maintainable software meet. The artifacts below form one progression: a classroom service becomes a more professional software design; a hard-coded network script becomes a validated and deterministic planning system; and that system gains persistent, auditable data. Together they provide measurable evidence of my growth and readiness to deliver secure computing solutions that create practical value.
